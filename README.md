# Gemini Live Translator（实时双语同传字幕）

基于 Google Gemini 官方 **Live Translate** 实时音频流 API 的浏览器双语同传字幕扩展。  
在观看外语直播、视频、公开课及线上会议时，实时捕获网页音频并流式输出「原文 + 译文」双语字幕。

> 当前版本：**v1.3.0**

---

## 一、核心功能

1. **原生流式双语同传**：基于 Gemini 3.5 Live Translate 协议，采用低延迟 `mediaChunks` 实时音频流分块与翻译，支持指定源语言转写锁频。
2. **双模式同传架构（标准模式 / 语境与术语增强）**：
   - 标准模式：零语境与零术语注入，保持原生纯净同传基线。
   - 语境与术语增强：支持自动识别当前网页视频标题、频道、话题标签与视频简介，内置覆盖 6 大类目（AI 与前沿科技、虚拟主播与ACGN、影视播客与文化、游戏电竞与军武、历史政经与社科、自然科学与公开课）、60 个细分专题、6,200+ 条多语种精选术语库，支持中英日关键词与英文词形自动匹配，按当前页面相关性动态优选 Top-100 预设词条并优先应用用户自定义术语表（支持 TXT / JSON 导入导出）；运行中切换模式、词库或切页时通过后台预热会话平滑过渡，音频不断流。
3. **智能断句与排版**：按语义标点与停顿边界自然分句落行，字幕连贯通顺；自动优化日文与中文字幕排版间距。
4. **独立悬浮窗体验**：
   - 支持自由拖拽移动与拉伸调整尺寸，具备精准的自动贴底追踪与历史回看锁定体验。
   - 可自定义背景透明度、毛玻璃模糊度与字体大小。
   - 支持「双语对照 / 仅译文 / 仅原文」三种显示模式。
5. **多音源捕获**：支持捕获当前网页内的视频/音频播放，亦可切换为麦克风输入。
6. **长会话稳定性**：内置连接状态自愈机制与长音频会话平滑维护，保障长时间直播观看连续稳定。
7. **网络自检工具**：设置页提供节点连接测试，直观查看当前链路握手状态。

## 二、安装与使用

### 1. 安装方式

支持 Chrome / Edge 等 Chromium 内核浏览器（建议 Chrome 120+）：

1. 下载并解压发布包 `Gemini_Live_Translator_v1.3.0.zip` 到本地固定目录；
2. 打开浏览器扩展管理页面 `chrome://extensions/`（Edge 为 `edge://extensions/`），开启右上角「开发者模式」；
3. 点击「加载已解压的扩展程序」，选择包含 `manifest.json` 的解压文件夹；
4. 安装完成后建议将插件图标固定至浏览器工具栏。

### 2. 配置与启动

1. 点击工具栏插件图标打开设置页：
   - **API 节点**：默认 Google 官方接口；若使用自定义反向代理或网关，切至「自定义代理」填入节点地址。
   - **API Key**：使用官方直连时填入 Gemini API Key；使用免密代理服务时可留空。
   - **同传模型**：默认 `models/gemini-3.5-live-translate-preview`。
   - **源语言与目标语言**：默认自动识别源语言并翻译为中文普通话；固定外语场景可指定源语言提升识别准确度。
   - **同传模式**：默认「标准模式」（纯净基线）；如需专名对齐与网页标题消歧，可切至「语境与术语增强」，按需勾选内置词库包或维护自定义词条（`原词 = 指定译法` 或保留专有名词）。
   - 点击「测试节点连接」确认链路正常，随后点击「保存并应用设置」。
2. 打开包含音频播放的网页（如 YouTube、Twitch 等视频或直播），点击浮窗启动按钮即可开启实时同传。
3. 点击浮窗顶部的设置图标可实时切换同传模式、管理词库、调节字号与透明度及一键复制字幕；点击重连图标可重置当前会话。

## 三、常见问题

| 现象 | 排查建议 |
|---|---|
| 一直显示“正在连接” | 可在设置页点击「测试节点连接」检查链路状态；若使用代理请确认网络与节点 WebSocket 连通性 |
| 已连接但未出现字幕 | 确认网页视频正在播放且未静音；浮窗在检测到有效语音输入后即会自动开始输出双语字幕 |
| 字幕断续或延迟偏大 | 多为网络波动或代理链路延迟，建议检查网络环境或切换更稳定的 API 节点 |
| 报错 1007 | 请确认当前安装的是最新发布的 v1.3.0+ 版本，确保协议字段配置完整 |

## 四、版本历史

- **v1.3.0**：全面升级语境感知与多领域专业术语库——内置词库扩展为 6 大领域分类（AI 与前沿科技、虚拟主播与ACGN、影视播客与文化、游戏电竞与军武、历史政经与社科、自然科学与公开课）、60 个细分专题与 6,200+ 条多语种专业术语（自动兼容迁移旧版已勾选词库）；网页语境识别扩展至视频与直播简介，支持中英日关键词、全角字符归一化、英文复数与词干派生匹配，按页面相关性动态优选 Top-100 预设词条（自定义术语表始终最高优先），并在悬浮窗与设置页实时预览命中的细分专题与生效词条数；标准模式保持纯净无额外语境注入基线。
- **v1.2.0**：新增「标准模式」与「语境与术语增强」双模式切换——标准模式保持零语境与零术语注入的纯净同传基线；增强模式支持在握手阶段注入网页标题、频道与标签语境，内置四大通用领域预设词库包（支持按需勾选与页面关键词边界匹配）及用户自定义术语表（支持 TXT / JSON 导入导出），并在运行中通过后台预热会话实现无感轮转生效；支持指定源语言转写参数传递；修复点击「回到最新」或滚轮回到底部后新字幕撑高容器引发异步滚动事件误判导致自动贴底滚动停滞的问题。
- **v1.1.0**：全面升级多网站音视频适配与系统稳定性——扩展支持原生 `<video>` / `<audio>`、动态单页应用切页自动重绑定、Shadow DOM 与嵌套 `iframe` 播放器捕获（含跨域标签页音频回退）、多轨混音与全屏/画中画自适应；优化悬浮窗指针拖拽与缩放锚点、设置面板动态防遮挡与低透明度字幕可读性，完善设置页状态同步、受限页面提示及完整键盘与无障碍导航；修复重连状态机与音频管线资源释放边界问题。

- **v1.0.8**：将悬浮窗、设置页及状态提示中的所有符号与 Emoji 替换为统一风格的内联矢量 SVG 图标，优化下拉选择器外观。
