# Gemini Live Translator（实时双语同传字幕）

基于 Google Gemini 官方 **Live Translate** 实时音频流 API 的浏览器双语同传字幕扩展。  
在观看外语直播、视频、公开课及线上会议时，实时捕获网页音频并流式输出「原文 + 译文」双语字幕。

> 当前版本：**v1.0.6**

---

## 一、核心功能

1. **原生流式双语同传**：基于 Gemini 3.5 Live Translate 协议，采用低延迟 `mediaChunks` 实时音频流分块与翻译。
2. **智能断句与排版**：按语义标点与停顿边界自然分句落行，字幕连贯通顺；自动优化日文与中文字幕排版间距。
3. **独立悬浮窗体验**：
   - 支持自由拖拽移动与拉伸调整尺寸。
   - 可自定义背景透明度、毛玻璃模糊度与字体大小。
   - 支持「双语对照 / 仅译文 / 仅原文」三种显示模式。
4. **多音源捕获**：支持捕获当前网页内的视频/音频播放，亦可切换为麦克风输入。
5. **长会话稳定性**：内置连接状态自愈机制与长音频会话平滑维护，保障长时间直播观看连续稳定。
6. **网络自检工具**：设置页提供节点连接测试，直观查看当前链路握手状态。

## 二、安装与使用

### 1. 安装方式

支持 Chrome / Edge 等 Chromium 内核浏览器（建议 Chrome 120+）：

1. 下载并解压发布包 `Gemini_Live_Translator_v1.0.6.zip` 到本地固定目录；
2. 打开浏览器扩展管理页面 `chrome://extensions/`（Edge 为 `edge://extensions/`），开启右上角「开发者模式」；
3. 点击「加载已解压的扩展程序」，选择包含 `manifest.json` 的解压文件夹；
4. 安装完成后建议将插件图标固定至浏览器工具栏。

### 2. 配置与启动

1. 点击工具栏插件图标打开设置页：
   - **API 节点**：默认 Google 官方接口；若使用自定义反向代理或网关，切至「自定义代理」填入节点地址。
   - **API Key**：使用官方直连时填入 Gemini API Key；使用免密代理服务时可留空。
   - **同传模型**：默认 `models/gemini-3.5-live-translate-preview`。
   - **目标语言**：选择需要翻译的目标语言（默认中文普通话）。
   - 点击「🔌 测试节点连接」确认链路正常，随后点击「保存设置」。
2. 打开包含音频播放的网页（如 YouTube、Twitch 等视频或直播），点击浮窗启动按钮即可开启实时同传。
3. 点击浮窗顶部的 ⚙️ 图标可快速调节字号、透明度与字幕显示模式；点击 🔄 可快速重置连接。

## 三、常见问题

| 现象 | 排查建议 |
|---|---|
| 一直显示“正在连接” | 可在设置页点击「测试节点连接」检查链路状态；若使用代理请确认网络与节点 WebSocket 连通性 |
| 已连接但未出现字幕 | 确认网页视频正在播放且未静音；浮窗在检测到有效语音输入后即会自动开始输出双语字幕 |
| 字幕断续或延迟偏大 | 多为网络波动或代理链路延迟，建议检查网络环境或切换更稳定的 API 节点 |
| 报错 1007 | 请确认当前安装的是最新发布的 v1.0.6+ 版本，确保协议字段配置完整 |
