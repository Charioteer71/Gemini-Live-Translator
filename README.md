# Gemini Live Translator (实时双语同传字幕)

基于 Google Gemini Live 双向流式 API 的浏览器双语同传字幕扩展。

在观看无中文字幕的外语视频（如影视动漫、公开课、演讲、歌曲现场、VTuber 直播、游戏解说等）时，本插件可实时捕获网页音频，直接生成流式双语同传字幕。

---

## 功能特点

* **多场景语境与断句适配**：
  * **综合通用模式**：适用于日常视频、访谈与纪录片。
  * **影视 / 动漫与剧场**：地道台词风格，角色交替对话快速断句，过滤背景音效干扰。
  * **VTuber / 网络直播**：口语自然连贯，准确传达主播语气与观众互动氛围。
  * **科技 / 学术演讲**：全文本流式输出，保持英文复杂长句完整性，避免连续发言中途被掐断。
  * **游戏实况 / 电竞**：适配快节奏游戏术语与临场反应。
  * **自动检测（测试中）**：基于当前视频元数据自动推荐匹配场景。
* **目标语言与防漂移**：
  * 支持实时输出为 **中文普通话**、**英语** 或 **日语**。
  * 包含语言巡检机制，防止大模型在长音频输入下偏离指定目标语言。
* **API 与代理支持**：
  * 支持直接填入 Google 官方 API Key 使用；
  * 兼容自建反代、中继与轮询网关，支持自定义 Endpoint。
* **浮窗交互与外观调节**：
  * 支持拖拽移动位置与拉伸窗口大小。
  * 可直接调节透明度、毛玻璃模糊度与字号。

## 安装教程

支持 **Google Chrome**、**Microsoft Edge** 及其他 Chromium 内核浏览器：

### 1. 下载并解压
1. 前往本仓库右侧的 **Releases** 页面，下载最新的发布压缩包（`.zip`）；
2. 将压缩包解压到本地固定目录（例如 `D:\Gemini_Live_Translator`）。
   > 提示：安装后请保留该文件夹，不要删除或移动路径。

### 2. 打开浏览器扩展管理页面
* **Chrome**：在地址栏输入 `chrome://extensions/`
* **Edge**：在地址栏输入 `edge://extensions/`
* 开启页面右上角的 **「开发者模式」** 开关。

### 3. 加载扩展程序
1. 点击左上角的 **「加载已解压的扩展程序」**；
2. 选择包含 `manifest.json` 的解压文件夹即可完成安装。

## 使用说明

1. **配置 API Key**：
   * 本插件为纯客户端开源工具，需使用您自行获取的 Google Gemini API Key；
   * 点击浏览器工具栏的插件图标打开设置面板（设置页右上角提供了前往 Google AI Studio 申请 Key 的官方入口链接）；
   * 填入您的 Gemini API Key（若使用中继/反代可填写自定义地址），点击「保存并应用设置」；
   > 💡 **配额说明**：Google 官方目前提供的标准免费 API 配额相对充裕，足以完全满足日常 1~2 个网页视频或直播的同时翻译需求。
2. **开启字幕**：
   * 打开包含音频的网页并播放视频；
   * 点击插件图标或浮窗中的播放按钮即可开始实时翻译。
3. **切换模式与调整**：
   * 插件会自动根据视频标题和标签匹配最佳语境模式，也可在浮窗底部手动切换；
   * 点击浮窗顶部的齿轮图标可即时调节透明度和字号；
   * 如遇网络波动，可点击顶栏的刷新按钮快速重置连接。
